# Ho Yeun Jae — AI automation portfolio

I use AI coding agents to turn operational requirements into working applications, identify failures through hands-on use, and drive investigation, repair and verification. My projects span AI messaging, school administration and volunteer scheduling.

My development approach is AI-assisted: coding agents handle detailed code analysis and implementation; I define behavior, reproduce problems, direct the work and evaluate the result. This portfolio reflects that collaboration.

Requirements: Node.js 22 or later and Python 3.10 or later. Follow each sample README for its test and demo commands. No provider account is needed for the offline samples.

## Working style

1. Describe the real task and expected result.
2. Reproduce the failure rather than relying on an agent's completion statement.
3. Use agents to inspect the relevant code, service or data path.
4. Check the repaired behavior and preserve a repeatable operating procedure.

Professional background: English–Korean translation, interpreting and teaching. These support clear requirements, precise documentation and communication with users.
